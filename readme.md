
# Iphone Sellados

## Descripción
Este proyecto es una página web sencilla para una tienda de iPhones.

La página muestra diferentes modelos de iPhone, sus características y una sección de contacto para realizar consultas.

## Tecnologías utilizadas
- HTML
- CSS
- Git
- GitHub

## Funcionalidades
- Listado de productos.
- Imágenes y videos de los celulares.
- Enlaces para contactar por correo electrónico y teléfono.
- Formulario para ingresar datos y seleccionar un modelo.

## Objetivo
Practicar lo aprendido en clase, aplicar estilos básicos con CSS y aprender a utilizar Git y GitHub para guardar y compartir el proyecto.
